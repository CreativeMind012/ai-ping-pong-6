# AI Ping Pong

A webcam-controlled ping pong game. Move your wrist in front of the camera to control your paddle — no keyboard or mouse needed.

🎮 **[Play it live](https://creativemind012.github.io/ai-ping-pong-6/)**

## How it works
Uses ML5.js to detect your body pose via webcam in real time. Your right wrist position maps directly to the paddle position on screen. Built with p5.js for the game rendering.

## Tech
- [ML5.js](https://ml5js.org/) — pose detection
- [p5.js](https://p5js.org/) — canvas rendering and game logic

## Run locally
Just open `index.html` in a browser. Allow camera access when prompted.
